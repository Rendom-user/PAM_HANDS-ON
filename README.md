## Petunjuk Penggunaan

1. Buka folder topik/hands-on terkait di **Android Studio** (`File > Open`).
2. Tunggu proses **Gradle Sync** selesai.
3. Buka file latihan pada masing-masing modul di bawah package `latihan/`.
4. Lengkapi kode pada bagian `TODO` yang tersedia.
5. Jalankan aplikasi pada target **Desktop** (`./gradlew :composeApp:run`) atau **Android** (`./gradlew :composeApp:installDebug`).
